AI Agent 开发

openai/openai-agents-python 发布 v1.0.0-alpha.1 ⭐️ 8.0/10

OpenAI 发布了 openai-agents-python SDK 的 v1.0.0-alpha.1 版本，新增了可选的 Codex 模型支持，并通过 PyO3 嵌入了未修改的 Rust 版 Codex Core，提升了性能和调用效率。该版本支持在运行时选择 CodexProvider，提供了丰富的工具链和审批流程，方便开发者集成和管理模型调用。官方提供了详细的安装说明、使用示例及兼容性说明，适用于 CPython 3.10 至 3.14 环境。实测中，示例程序成功识别野生动物图片并调用 Python 工具生成结构化报告，验证了功能的有效性。该版本仍处于 alpha 阶段，功能和接口可能会继续调整。
