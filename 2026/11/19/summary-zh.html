datasette-arrows 0.1a0 插件发布 ⭐️ 7.0/10

datasette-arrows 0.1a0 是一个为 Datasette 提供 Apache Arrow 格式流式导出功能的新插件，基于 Datasette 1.0a43 版本新增的插件流式导出接口实现。该插件允许用户无需将全部数据加载到内存，即可导出大型数据表，支持与 DuckDB、pandas、Polars 等工具兼容。安装后，导出对话框新增 Arrow 选项，方便用户选择高效的数据导出格式。该版本为 alpha 预览，主要作为 Datasette 流式导出功能的补充示例。

Daniel Stenberg 谈 curl 的 Rust 重写与持续手动改进的对比 ⭐️ 7.0/10

Daniel Stenberg 指出，虽然 AI 代理将 curl 的 18.5 万行 C 代码转换成了 34 万行 Rust 代码，但在同一时间内，curl 项目通过手动合并了 300 多个提交，修复了 200 多个漏洞和安全问题。作者强调，自动生成的 Rust 重写版本尚未包含这些持续的手动改进和安全修复，反映出 AI 生成代码在实际生产环境中难以跟上持续维护和安全更新的步伐。这一对比揭示了 Rust 重写适用于代码迁移和安全性提升的潜力，但目前仍需依赖人工持续维护以保证代码质量和安全。文中未提供具体代码示例，相关讨论可见于 Daniel Stenberg 的博客文章。
