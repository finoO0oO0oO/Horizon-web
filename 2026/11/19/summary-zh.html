datasette-arrows 0.1a0 插件实现 Apache Arrow 流式导出 ⭐️ 7.0/10

datasette-arrows 0.1a0 是一个为 Datasette 提供 Apache Arrow 流式导出功能的新插件。该插件利用 Datasette 1.0a43 版本新增的插件钩子 register_output_renderer()，实现了类似 CSV 和 TSV 的流式导出，支持导出大规模数据而无需全部加载到内存中。用户通过安装该插件后，在导出对话框中即可选择 Arrow 格式导出，方便与 DuckDB、pandas、Polars 等工具集成。文中附带了插件安装方法、使用说明及界面截图，适用于需要高效导出大数据集的开发者。该功能基于作者 Simon Willison 和 Claude Fable 的合作开发，实测效果良好。

Daniel Stenberg 谈 curl 的 Rust 重写与持续改进 ⭐️ 7.0/10

Daniel Stenberg 指出，虽然自动化工具将 curl 的 18.5 万行 C 代码转换成了 34 万行 Rust 代码，但在同一时间内，curl 项目通过持续的手动维护和改进，合并了 300 多个提交，修复了 200 多个漏洞和安全问题。作者强调，自动化 Rust 重写尚未达到持续改进和安全修复的水平，体现了实际生产环境中人工维护的重要性。
