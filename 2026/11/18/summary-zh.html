AI Agent 开发

Simon Willison 的外部沙箱方案保障 AI 编码代理安全执行代码 ⭐️ 8.0/10

Simon Willison 介绍了一种外部沙箱模式，用于安全地运行由 AI 编码代理执行的代码。该模式将代码执行隔离在专用沙箱中，而代理本身运行在沙箱之外，降低了因错误或提示注入攻击导致的风险。为演示该模式，作者与 Prime Radiant 合作发布了三种开源沙箱服务器实现，分别基于 v86 的 WebAssembly Alpine Linux、Apple Containers 中的 Alpine Linux 以及微软 Quicksand 沙箱库，均提供统一的本地 API 接口。此外，这些沙箱支持 HTTP/HTTPS 允许列表代理和凭证替换机制，方便控制网络访问和安全调用认证接口。该方案适用于本地 AI 模型和编码代理的安全代码执行，文档和代码均开源，便于开发者复用和扩展。

使用服务工作线程和 Pyodide 在浏览器中运行完整的 Datasette Python 应用——Datasette Lite ⭐️ 8.0/10

Simon Willison 开发的 Datasette Lite 通过 Pyodide 和服务工作线程实现了在浏览器中运行完整的服务器端 Datasette Python 应用，支持交互式浏览 SQLite 数据库及插件，无需服务器环境。该方案利用服务工作线程拦截 HTTP 请求，加载指定版本的 Datasette、SQLite 及插件，支持通过 URL 参数灵活配置，方便演示和调试。文中提供了详细的使用示例和插件安装方法，展示了其在开发过程中的实际应用和兼容性优势。
