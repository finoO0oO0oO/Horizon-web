Simon Willison 的外部沙箱方案保障 AI 编码代理代码执行安全 ⭐️ 8.0/10

Simon Willison 介绍了一种外部沙箱模式，用于安全执行 AI 编码代理生成的代码，避免本地模型实验中因错误或提示注入攻击导致的风险。该模式将代码执行隔离在专用沙箱内，而代理本身运行在沙箱外。为演示该模式，作者发布了三种开源沙箱服务器实现，分别基于 v86 WebAssembly 运行 Alpine Linux、Apple Containers 中的 Alpine Linux 以及微软 Quicksand 沙箱库，均提供统一的本地 API 接口。此外，这些沙箱支持 HTTP/HTTPS 允许列表代理和凭证替换机制，方便控制网络访问和安全认证。该方案适合开发者在本地安全地试验和控制 AI 代码执行。

Datasette Lite：使用服务工作线程和 Pyodide 在浏览器中运行完整的 Datasette Python 应用 ⭐️ 8.0/10

Datasette Lite 是 Simon Willison 将 Datasette Python 应用移植到浏览器端的项目，利用 WebAssembly 和 Pyodide 实现完整的客户端运行。通过服务工作线程，Datasette Lite 能够动态加载 SQLite 数据库、插件和不同版本的 Datasette，无需服务器支持即可浏览和操作数据。该方案支持从 PyPI 或 GitHub 加载特定版本和插件，适合开发者进行无服务器的演示和数据探索。作者提供了详细的 URL 参数说明和示例，展示了其在实际开发中的应用，如调试分页问题的演示链接。相比早期版本，新的实现通过服务工作线程拦截 HTTP 请求，解决了 JavaScript 执行和资源加载的问题，使客户端体验几乎与服务器端一致。

GPT‑6.2 Astra 与 GPT‑6.2 Sol 模型实测对比 ⭐️ 7.0/10

Simon Willison 对 OpenAI 新发布的 GPT‑6.2 Astra 和 GPT‑6.2 Sol 模型进行了详细的实测评测，涵盖了价格、API 支持及输出质量。Astra 定位为高端复杂任务模型，价格较前代有所下降，Sol 则保持高性价比，适合日常使用。通过鹈鹕骑自行车的插画和三维动画生成测试，展示了两者在细节表现和动画生成能力上的差异。尽管 Astra 在部分基准测试中表现不及竞争对手 Claude Fable 5.2，且存在沟通风格上的争议，但其在长任务管理多子代理方面表现出一定优势。文章提供了丰富的示例链接和代码入口，适合开发者参考最新模型的实际应用效果。
